# 说明
<p>点击歌曲红心❤️旁按钮或⚙️设置页链接打开/关闭◲小窗</p>
<p>可拖动↔↕可调整大小</p>
<p>🐀鼠标移上◲小窗显示控制按钮</p>
<p>也可以敲击 空格来控制▶️播放⏸️暂停</p>
<p>↗返回和x关闭的效果可自定义</p>
